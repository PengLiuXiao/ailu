# Triage Labels

工程 Skills 使用五种标准 triage 角色。本文件定义标准角色在当前 GitHub 仓库中对应的实际标签。

| Skill 标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或实现 |
| `wontfix` | `wontfix` | 已决定不处理 |

当 Skill 提到角色，例如“添加 AFK-ready 标签”时，使用本表右侧对应的 GitHub 标签。

如果未来更换标签命名，只修改右侧 GitHub 标签列，避免在各个 Skill 中分别修改。
